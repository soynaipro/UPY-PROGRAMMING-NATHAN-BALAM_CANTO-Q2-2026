# AI Powered Study Game

## 🚀 Project Overview
**AI Powered Study Game** is an AI-driven educational tool designed to transform passive reading into active, gamified learning. This project directly aligns with the **Engineering Week 2026** central themes:

- **Agents:** Integrates an Autonomous Educational NLP Agent that perceives unstructured study text, analyzes semantics, and acts by generating structured quizzes and rationale feedback.
- **Sustainability:** Supports UN Sustainable Development Goal 4 (**Quality Education**) and eliminates physical paper waste through a 100% digital self-evaluation pipeline.

## 📁 Repository Contents
- `main.py`: Core game loop with infinite-loop safety validations.
- `ai_agent.py`: NLP Agent integration and text-chunking logic.
- `Project.pdf` & `Follow-Up Presentation.pdf`: Architecture diagrams and peer-review defense documentation.
